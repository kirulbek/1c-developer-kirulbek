# 1C Developer (Kirulbek)

Личный Skill для Codex по разработке 1С: ошибки, запросы, пошаговая отладка, изменения кода и организация задач по проектам.

## Установка на другом компьютере

На домашнем компьютере откройте Codex и попросите:

> Установи Skill `1C Developer (Kirulbek)` из GitHub: репозиторий `kirulbek/1c-developer-kirulbek`, папка `skills/1c-developer-kirulbek`.

Codex использует `$skill-installer`, скачает Skill и установит его в личный каталог. После этого он доступен в следующем чате, например через `$1c-developer-kirulbek`.

Файлы Skill синхронизируются обновлениями репозитория только после повторной установки/обновления. Локальная история задач в этот репозиторий не записывается: она остаётся в `Documents/Codex/1c-developer-kirulbek-data/` на каждом компьютере отдельно.

## MCP-инструменты 1С

Skill содержит инструкции, но не устанавливает серверы MCP и не включает в репозиторий код серверов, базу справки 1С, исходники или локальные настройки. На каждом компьютере отдельно установите и подключите `onec_help` и `onec_bsl`, следуя [инструкции по MCP](docs/MCP-SETUP.md). Без них Skill всё ещё может разбирать код своими знаниями, но не сможет подтвердить ответ справкой 1С или запустить статическую диагностику.

## Содержимое

- `skills/1c-developer-kirulbek/SKILL.md` — главные инструкции и маршрутизация по режимам.
- `skills/1c-developer-kirulbek/references/` — правила 1С, задачи и комментарии доработок.
- `docs/MCP-SETUP.md` — настройка локальных MCP-серверов.
